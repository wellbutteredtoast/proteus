Proteus
-----------------
<img align="left" style="width:64px" src="./static/ProteusLogo01.png" width="64px">

Proteus is a passion project general purpose game engine implemented in C++. It's designed at its core to be simple, yet powerful. It's also designed to be extremely efficient on the CPU and GPU. It's code-only. No editor magic here, just you and the APIs. 

<br>

Current Progress
-----------------

Proteus is currently **unstable** and not fit for any production tasks yet. The use of unstable versions or live `main` for production is not recommended as its stability cannot be guaranteed. Please wait until tagged releases, or stabilise your own fork of Proteus, whichever is most convenient for you.
