# Proteus

Proteus is a passion project fueled by a hackathon prompt:
<!-- However as I am the VP of MUNCSS where this hackathon is hosted, I cannot submit this -->
```
"Improve something you use daily, or solve a problem you encounter in your day-to-day life."
```

Proteus is just that, a game engine which is implemented in C++. It's general purpose, 3d only, and that is pretty much it. Nothing overly fancy about this. Purpose-built, viciously efficient across the board.

## Current Progress

Proteus is currently **unstable** and not fit for any production tasks yet. The use of unstable versions or live `main` for production is not recommended as its stability cannot be guaranteed. Please wait until tagged releases, or stabilise your own fork of Proteus, whichever is most convenient for you.
